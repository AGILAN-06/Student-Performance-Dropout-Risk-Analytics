# Student Performance & Dropout Risk Analytics

## About the Project
An educational data analytics project that analyzes student performance, course withdrawal patterns, and learning activity using Python and Machine Learning.

## Technologies
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Google Colab

## Dataset
Open University Learning Analytics Dataset (OULAD).

## Key Features
- Data cleaning and preprocessing
- Exploratory Data Analysis
- Statistical hypothesis testing
- Student withdrawal analysis
- Random Forest classification
- Learning activity analysis
- Student support recommendations

## Project Notebook
`Student_Performance_Dropout_Risk_Analytics.ipynb`

## Dataset Source
https://archive.ics.uci.edu/dataset/349/open+university+learning+analytics+dataset
